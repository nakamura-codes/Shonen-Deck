# Efeitos visuais

- `pvfx/` — **PVFX Foundry 1.0.0**, por Pixel VFX Studio. Os sprite-sheets e manifests são
  dedicados ao domínio público (**CC0 1.0**); ver `pvfx/LICENSE.txt` e `pvfx/THIRD_PARTY_NOTICES.txt`.
- `outros/explosao_fogo.png` — "Fire Effect 2" (Explosion SpriteSheet), enviado pelo usuário.
- `outros/fumaca.png` — "Free Smoke Fx Pixel 2" (folha 04), enviado pelo usuário.

Os dois pacotes de `outros/` vieram sem arquivo de licença: confirme os termos de uso na página
de onde foram baixados antes de publicar o jogo.

Para trocar ou adicionar efeitos, coloque os arquivos aqui e rode `npm run art:fx`.
